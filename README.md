## About

I build backend systems focused on correctness, security, and clean architecture — not just working code. My work centers on **FastAPI**, **PostgreSQL**, and **SQLAlchemy**, structured around repository patterns, service layers, and dependency injection, then shipped as containerized, production-deployed APIs.

I care about how a system behaves under real conditions: authentication flows that don't leak state, migrations that don't break production, and APIs that are documented well enough that no one has to ask how they work.

**Currently focused on:** production API design, authentication systems, and backend architecture that scales cleanly from prototype to production.

## Featured Projects

### 🏛 CampusOS — College ERP Backend
**Flagship Project**

Production-grade College ERP system built to handle multi-role academic operations — students, faculty, and administration — behind a single, secured API surface.

**Architecture**
- Layered design: Repository Pattern → Service Layer → API Layer, fully decoupled via Dependency Injection
- JWT-based authentication with Role-Based Access Control (RBAC) across student, faculty, and admin scopes
- PostgreSQL with SQLAlchemy 2.0 (async), versioned schema migrations
- Redis-backed caching for high-read endpoints
- Fully containerized with Docker, deployed to production on Railway

**Core Features**
- Role-scoped dashboards and permissions
- Secure session and token lifecycle management
- Structured error handling and request validation via Pydantic
- Interactive OpenAPI documentation

**Stack:** `FastAPI` `PostgreSQL` `SQLAlchemy 2.0` `Redis` `Docker` `JWT` `RBAC`

A standalone, production-ready authentication backend built as a reusable auth service — the kind of system real products depend on.

**Architecture**
- JWT access + refresh token rotation

- Alembic-managed database migrations
- Fully Dockerized for consistent deployment

**Core Features**
- Email verification flow
- Secure password reset with token expiry
- Refresh token rotation to reduce session hijacking risk

**Stack:** `FastAPI` `PostgreSQL` `SQLAlchemy` `Alembic` `JWT` `Docker`
